# SafeCore

A SafeCore é um projeto educacional desenvolvido como avaliação principal do último semestre do curso Técnico em Desenvolvimento de Sistemas do SENAI. O objetivo é criar uma solução de monitoramento inteligente para ambientes industriais, integrando dispositivos de IoT a um aplicativo mobile capaz de acompanhar, em tempo real, as condições de segurança da fábrica.

O sistema utiliza sensores para monitorar fatores como presença de gases, temperatura, pressão e ventilação. Essas informações são coletadas por microcontroladores e transmitidas para a aplicação mobile, onde o usuário visualiza um mapa da fábrica com a localização dos sensores, o status de cada área e alertas sobre possíveis riscos.

Além do monitoramento, o SafeCore simula ações preventivas diante de situações críticas, como a identificação de vazamentos de gás, podendo indicar áreas de risco, acionar sistemas de ventilação, isolar setores afetados e notificar os responsáveis pela operação.

Para seu desenvolvimento, o projeto emprega tecnologias e metodologias estudadas ao longo do curso, incluindo Figma para prototipação da interface, Flutter para o desenvolvimento do aplicativo mobile, SCRUM como métodologia de organização e gerenciamento de prioridades, Internet das Coisas (IoT), sensores, microcontroladores e protocolos de comunicação entre o sistema embarcado e a interface do usuário, proporcionando uma solução integrada, prática e alinhada aos conceitos da Indústria 4.0.
